# Python Tasks

![Python](https://img.shields.io/badge/Python_3.12-3776AB?logo=python&logoColor=white)

Four standalone command-line programs written for the **Python Programming** course (7.5 ECTS) at Kristiania University College, covering control flow, file handling, object-oriented programming and basic data structures.

## What's in here

| File | What it does |
| --- | --- |
| `Question_1/` | Word guessing game: guess letters to reveal a randomly chosen word |
| `Question_2.py` | Library system built with classes: add and remove books, check them in and out |
| `Question_3.py` | Menu-driven bank account with deposits, withdrawals, interest and balance |
| `Question_4.py` | Function that checks whether a string is a palindrome |

## Run it

Needs Python 3.12. Each question runs on its own:

```bash
python Question_2.py
```
